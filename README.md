🚀 DevOps Turma B

Projeto desenvolvido durante as atividades da **Turma B de DevOps**, com o objetivo de praticar conceitos de desenvolvimento, versionamento e colaboração utilizando Git e GitHub.

## 📋 Sobre o projeto

Este repositório contém a estrutura inicial do projeto desenvolvido pela Turma B.

Atualmente, o projeto possui uma página HTML básica utilizada como ponto de partida para o desenvolvimento e evolução da aplicação.

## 🛠️ Tecnologias utilizadas

* HTML5
* Git
* GitHub
* Markdown

## 📂 Estrutura do projeto

```text
devops_turma_B/
├── .github/
│   └── pull_request_template.md
├── index.html
└── README.md
```

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/luiznando08/devops_turma_B.git
```

### 2. Acesse a pasta do projeto

```bash
cd devops_turma_B
```

### 3. Execute o projeto

Como o projeto atualmente utiliza HTML puro, basta abrir o arquivo `index.html` em um navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para executar a página localmente.

## 🌱 Desenvolvimento

O projeto está em desenvolvimento e poderá receber novas funcionalidades, melhorias na estrutura e novas tecnologias conforme as atividades da turma forem realizadas.

## 🤝 Contribuição

Para contribuir com o projeto:

1. Crie uma nova branch:

```bash
git checkout -b feature/minha-alteracao
```

2. Realize suas alterações.

3. Faça o commit:

```bash
git add .
git commit -m "feat: adiciona nova funcionalidade"
```

4. Envie a branch para o GitHub:

```bash
git push origin feature/minha-alteracao
```

5. Abra um **Pull Request** para revisão.

## 📌 Pull Requests

O projeto possui um template de Pull Request em:

```text
.github/pull_request_template.md
```

Utilize o template ao criar novos Pull Requests para manter as alterações organizadas e facilitar o processo de revisão.
